# Перевод субтитров: английский → русский

Настольная программа для Windows. Она локально распознаёт английскую речь через Whisper из `J:\audiobook`, переводит встроенной моделью английский → русский, сохраняет `.ru.srt` и вшивает субтитры в исходный MP4. При включённой и загруженной локальной Qwen2.5-VL программа дополнительно учитывает соседние реплики и кадр видео для каждой группы субтитров.

**Ollama не требуется.** Файл модели перевода лежит в папке `models` репозитория и отслеживается через Git LFS. Перевод и распознавание работают локально.

## Что установить

- Windows 10 или 11, 64-разрядная система.
- Python 3.10 или 3.11: [загрузить для Windows](https://www.python.org/downloads/windows/). В установщике включите **Add Python to PATH**. Установщик проекта сам выберет Python 3.11 или 3.10, даже если на компьютере также есть более новая версия.
- FFmpeg и ffprobe для создания MP4 с вшитыми субтитрами. Например, установите командой `winget install Gyan.FFmpeg`, затем откройте новое окно командной строки и проверьте команды `ffmpeg -version` и `ffprobe -version`.
- Локальный ASR-проект в `J:\audiobook`, его среда `.venv_cosyvoice3` и кэш Whisper `medium.pt` или `small.pt` в `%USERPROFILE%\.cache\whisper`. По умолчанию выбрана модель medium; если её нет, используется small.

## Запуск

1. Клонируйте репозиторий или откройте папку проекта. Папка `models` должна остаться рядом с `app.py`.
2. Дважды щёлкните `start.bat`: при первом запуске он сам установит зависимости, а затем откроет программу. Установку можно также запустить отдельно через `install.bat`.
3. Выберите видео, выберите medium или small и нажмите **Распознать, перевести и сохранить**. Распознавание обрабатывает дорожку отрезками по пять минут, использует таймкоды отдельных слов для субтитров и показывает прогресс. Неразмеченные длинные фразы пропускаются вместо показа одной строки десятки секунд.

SRT сохраняется в папку `subtitles` рядом с видео, чтобы видеоплеер не загрузил его поверх уже вшитых субтитров. При отключённом вшивании `.ru.srt` сохраняется рядом с видео. Исходный MP4 заменяется версией с субтитрами, а прежний файл сохраняется рядом как `имя.original.mp4` (или с отметкой времени, если такая копия уже есть). Видео перекодируется в H.264, звук — в AAC. Замена выполняется только после проверки готового MP4.

## Модель перевода и контекст видео

В репозитории хранится Argos Translate EN→RU версии 1.9, файл модели около 196 МБ. Она работает локально и не отправляет текст во внешний переводчик. Это встроенный резервный переводчик.

Для более связного перевода включите настройку **«Улучшать контекст локальной Qwen2.5-VL…»** и заранее загрузите Qwen2.5-VL в установленном локально LM Studio. Программа обращается только к локальному адресу `127.0.0.1`; Ollama, облачный API и интернет для перевода не используются. Модель получает группы соседних реплик и один уменьшенный кадр исходного видео на группу, чтобы лучше понимать местоимения, имена, сцену и неоднозначные выражения. Тайминги и границы субтитров остаются прежними. Если локальный сервер или модель недоступны либо запрос не проходит, эта группа переводится встроенным Argos. Новая отдельная библиотека Python для этого не нужна.

Qwen2.5-VL — дополнительная локальная модель и не входит в Git-репозиторий из-за размера; её нужно один раз иметь в LM Studio. На компьютере без неё приложение продолжает работать через встроенную Argos-модель. В запросе к модели явно указано сохранять обсценную лексику без смягчения, насколько это позволяет сама модель.

ASR использует установленный Whisper из проекта аудиокниг. В текущем прогоне модель medium обработала 41 минуту 22 секунды видео примерно за 4 минуты 15 секунд на RTX 4060 Ti. Скорость зависит от видео, модели и загрузки GPU.

Если часть строк перевести не удалось, программа оставит в них английский оригинал и сообщит их количество.

## Файлы

- `app.py` — приложение.
- `work/asr_video_worker.py` — локальный ASR-процесс, использующий окружение `J:\audiobook`.
- `models/translate-en_ru-1_9.argosmodel` — встроенная модель перевода.
- `requirements.txt`, `install.bat`, `start.bat` — установка и запуск.

## Журнал ошибок

Ошибки приложения записываются в `logs/subtitle_translator.log`; сбои запуска и установки — в `logs/startup.log`. Основной журнал ротируется автоматически и хранит последние файлы логов. Если приложению нельзя записывать в папку проекта, журнал сохраняется в `%LOCALAPPDATA%\SubtitleTranslator\logs`.
