# Перевод субтитров: английский → русский

Настольная программа для Windows. Она локально распознаёт английскую речь, переводит её встроенной моделью английский → русский, сохраняет `.ru.srt` и по желанию вшивает субтитры в `.ru.mp4`.

**Ollama не требуется.** Файл модели перевода лежит в папке `models` репозитория и отслеживается через Git LFS. После установки зависимостей перевод работает без интернета. В первый запуск faster-whisper скачает выбранную модель распознавания.

## Что установить

- Windows 10 или 11, 64-разрядная система.
- Python 3.10–3.12: [загрузить для Windows](https://www.python.org/downloads/windows/). В установщике включите **Add Python to PATH**.
- FFmpeg и ffprobe для создания MP4 с вшитыми субтитрами. Например, установите командой `winget install Gyan.FFmpeg`, затем откройте новое окно командной строки и проверьте команды `ffmpeg -version` и `ffprobe -version`.

## Запуск

1. Скачайте проект кнопкой **Code → Download ZIP** на GitHub или клонируйте репозиторий. Папка `models` должна остаться рядом с `app.py`.
2. Запустите `install.bat` и дождитесь установки.
3. Запустите `start.bat`.
4. Выберите видео, выберите размер модели распознавания и нажмите **Распознать, перевести и сохранить**.

Рядом с оригиналом появятся `имя.ru.srt` и, если включено вшивание, `имя.ru.mp4`. Видео перекодируется в H.264, звук — в AAC.

## Модель перевода

В репозитории хранится Argos Translate EN→RU версии 1.9, файл модели около 196 МБ. Она работает локально и не отправляет текст во внешний переводчик. Это специализированный машинный переводчик без отдельного фильтра на обсценную лексику; точность и выбор формулировок зависят от модели. Он компактнее большой языковой модели и не обладает её глубоким контекстным пониманием.

Модели faster-whisper: `tiny` и `base` быстрее; `small` — баланс скорости и точности; `medium` и `large-v3` требуют больше памяти. Модель скачивается при первом запуске и затем работает локально.

Если часть строк перевести не удалось, программа оставит в них английский оригинал и сообщит их количество.

## Файлы

- `app.py` — приложение.
- `models/translate-en_ru-1_9.argosmodel` — встроенная модель перевода.
- `requirements.txt`, `install.bat`, `start.bat` — установка и запуск.
